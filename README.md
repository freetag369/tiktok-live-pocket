# TikTok LIVE ポケット

TikTok LIVE の **コメント・入室(初見 / 何回目)・ギフト(画像つき)・いいね(通知とランキング)・ハイライト(日別のメンバー一覧)** を、配信用スマホとは別の iPhone で見るためのアプリです。
PC は不要で、iPhone 単体で [Euler Stream](https://www.eulerstream.com/) の Cloud WebSocket に直接つないで受信します。

Safari で開いて「ホーム画面に追加」すると、全画面のアプリとして使えます(PWA)。

- 公開 URL: **https://freetag369.github.io/tiktok-live-pocket/**
- ライセンス: AGPL-3.0(PC 版 [tiktok-live-stats](https://github.com/freetag369/tiktok-live-stats) と同じ)

## iPhone での初回設定

1. Safari で上の URL を開く
2. 右上の ⚙️ →「配信者名」に TikTok の @ の後ろ(例: `metafact8`)を入れる
3. 「Euler Stream API キー」に、eulerstream.com の無料 Community アカウントで発行したキーを貼る(PC 版で使っているキーと同じで OK)
4. ✕ で閉じて、右上の **接続** を押す
5. Safari の共有ボタン(□に↑)→「ホーム画面に追加」

配信が始まっていないときは「配信待ち」になり、60 秒ごとに再確認します(最長 4 時間)。

## 画面

| 場所 | 内容 |
|---|---|
| ヘッダ | 接続状態(● 緑=受信中 / 黄=接続・待機中 / 赤=停止)、配信者名、同接 👀、この配信の累計 💎、**接続 / 切断** ボタン(デモ再生中に押すとデモを止めて接続) |
| タブ | すべて / コメント / 入室 / ギフト(ギフトタブは画像が大きい)/ いいね(この配信のタップ数ランキング。直近 3 秒にタップした人は行が光り、上の「いま:」に名前が出る)/ やり取り(下記)/ ハイライト(日付を選んで、その日にアクションした人の一覧。下記)。幅が足りないときはタブを横にスクロールできます |
| やり取り | **受信中の配信**でコメント・ギフト・いいねをくれた人の一覧(入室だけの人は出ない)。新しい順 / 多い順(💎 → コメント → いいね)、名前・メモで絞り込み。人をタップすると **その配信でのその人の履歴**(コメント・ギフト・入室・フォロー、いいねは回数と最後の時刻)が並び、行タップか「📝 メモを書く」でそのままメモを書けます。名前・バッジ・数・メモは上に 1 回だけ出し、コメントは時刻と本文だけの行になります。🧹 で画面を消しても 🗂 アーカイブから補うので消えません(いいねの回数は再読み込みでリセット) |
| 行 | アイコン + 名前 + **初見** または **N回目** バッジ。ギフターレベル(バッジ)持ちの入室は **Lv.N** 付きで出ます(TikTok はこの入室を別種のメッセージで送るため、専用に拾っています)。ギフトは画像 + 名前 + ×連打数 + 💎。しきい値(既定 100💎)以上は金枠で大きく。リスナーメモがある人は名前の横に **(よみがな)**、下に **📝 メモ** が金色で出ます |
| 行をタップ | その人の **メモ・前回・よみがな** を書くシートが開きます(配信中でも配信後でも) |
| 下 | 新着は下に積まれます。上にスクロールすると追従が止まり「↓ 新着 N 件」で戻れます。さらに前は「↑ さらに前の 300 件を表示」で遡れます |
| 一番下の枠 | すべて / 入室タブの一番下に **ニックネームなしの入室** の固定枠(入室 3 行ぶん)。ニックネームを設定していない人(TikTok の既定名 `user` + 数字のまま。空で届くことはありません)の入室はここにまとめ、上のフィードには流しません。新しい順に下へ積まれ、古い分は枠の中を上へスクロール。行をタップするとメモを書けます。入室の件数・アーカイブはこれまで通り含みます |
| 右下 | いいねが届くと「❤️ +N」のポップアップ(最大 3 人、連打中は数が伸びて 3 秒で消える)。設定の「いいねの通知を表示」で OFF にできます |
| 🧹 リセット | タブの右端。**画面の行**を消します(確認あり)。🗂 アーカイブ・タブの数・💎 は残ります |
| 🗂 アーカイブ | 配信ごとにコメント・入室・フォロー・ギフト・いいねを全部残して見返せます(下記) |

## 画面の履歴(🧹 でリセットするまで残ります)

- **コメントとギフトは全部残ります**。配信が長くても古い順に消えることはありません
- **入室・フォロー・シェア**は直近 500 件だけ(多いときは古いものから落ちます)
- 次の配信が始まっても前の分は消えず、境目に **「── 新しい配信 ──」** の区切り線が入ります
- アプリを閉じて開き直しても、同じ画面が戻ります(この iPhone の IndexedDB に残しています)
- 消えるのは **タブ右端の 🧹** を押して「消す」を選んだときだけです。🗂 アーカイブ・タブの件数・💎 はそのまま残ります
- 画面には最新の 300 行を出し、上へスクロールして「↑ さらに前の 300 件を表示」で遡ります(行が何万件でも動作は軽いままです)
- タブの件数と 💎 は「**その配信の**合計」なので、🧹 しても変わりません

## ハイライト(日別のメンバー一覧)

「ハイライト」タブでは日付を選び、その日に **コメント・いいね・フォロー・ギフト** をしたメンバーを一覧できます。日付と時刻は日本時間で、同じ日の複数の配信はまとめ、最後にアクションした人から並びます(入室・シェアだけの人は出ません)。

- 日付を選ばなければ「今日」を表示し、0 時を過ぎると自動で次の日に切り替わります。日付を選ぶと、ほかのタブへ行って戻ってもその日のまま(「今日へ」で戻ります)
- メンバーを押すと **メモ・前回・よみがな** の入力の下に、その人のその日の履歴(時刻と内容)が出ます
- いいね・ギフトは受け取った個数を合計します。連打ギフトは累計の数に更新されます。ギフト名は日本語で出ます
- 一覧は受信に合わせて 1 秒ごとに更新されます
- 履歴はアーカイブから読むので、アーカイブの **保存期間(残す配信の数)・配信の削除・全消去** に連動します。アーカイブの保存が OFF の間の記録はメモリにだけ置き、アプリを閉じると消えます。メモリに置くのは新しい 20,000 件まで(いいねは 1 人 1 分で 1 件)で、長い配信で超えると古い方から消え、ハイライトにそう表示されます
- いいねはこのバージョンから記録します(それより前のいいねは復元できません)
- デモ再生中はデモの見本だけを出し(「デモ」と表示)、デモが終わると本物の履歴とメモに戻ります(本画面はデモの行のまま)。ここで書いたメモは本物のメモに残ります

## 来店回数の数え方

- その配信(roomId)で **初めて姿を見せた瞬間** に +1(入室メッセージは混雑時に間引かれるので、コメントやギフトでも数えます)
- 初見かどうかは +1 する前の回数が 0 かで決め、その配信中は固定
- 再接続・アプリ再起動で同じ配信を見ても二重に数えません
- 履歴はこの iPhone のブラウザ(IndexedDB)にだけ保存されます。Safari のサイトデータを消すと失われます

## リスナーメモ

「前回」欄には前回のお礼ややり取りを500文字まで手入力できます。自分で編集・消去するまで次の配信にも残ります。メモの下に「前回：内容」として、フィード・リスナー一覧・やり取り・ハイライト・いいねランキング・アーカイブのユーザー行に表示されます。アーカイブでも現在のメモを表示します。「前回」だけでも保存・検索でき、「メモありだけ」の対象になります。削除ボタンはメモ・前回・よみがなをまとめて消去します。

「誕生日 3/4」「ゲームの話が好き」「名前は『たろう』と読む」のような覚え書きをリスナーごとに残せます。書いたメモは次の配信から、その人が **入室・コメント・ギフト** した瞬間に行の中に表示されます(配信中に書き直しても、その人の行はすぐ差し替わります)。

| どこで書く | 内容 |
|---|---|
| フィードの行をタップ | 配信中に思いついた瞬間に書く。名前・回数を確認しながら、メモ・前回(それぞれ500 字まで)とよみがな(50 字まで)を入力 → 保存 |
| 設定 →「👥 リスナー一覧・メモ」 | 保存済みの来店履歴を最近来た順に一覧。名前・@ハンドル・メモ・前回で検索、「メモありだけ」で絞り込み。アプリを閉じた翌日でもここから書けます |

- メモは来店履歴とは別に IndexedDB に保存されます。「来店履歴をリセット」してもメモは消えません
- バックアップ JSON に含まれます(統合 = 新しいメモを残す / 置き換え = メモも置き換え)
- デモの行から書いたメモは使い捨てで、本物のメモには残りません(たろうさんに見本のメモが入っています)。デモが終わって本画面にデモの行が残っている間も同じです。ハイライトはデモが終わると本物の行に戻るので、そこから書いたメモは本物に残ります

## アーカイブ(配信ごとの履歴)

受信した行は配信(roomId)ごとに **全部** この iPhone の IndexedDB に残ります。右上の 🗂 で開きます。画面を 🧹 でリセットしても、こちらは消えません。

いいねは 1 通ごとではなく **人ごと・1 分ごとに 1 行** にまとめて残します(タップ数は合計)。本画面のフィードには流しませんが、アーカイブの「すべて」、CSV・JSON の書き出し、「アーカイブも含める」バックアップには入ります。

| 画面 | 内容 |
|---|---|
| 一覧 | 配信の日時・配信者・💬 コメント数・🚪 入室数・🎁 ギフト数・💎 累計。受信中の配信には「受信中」 |
| 詳細 | 本画面と同じ見た目で時刻順。タブ(すべて / コメント / 入室 / ギフト)と検索(名前・本文・ギフト名)で絞り込み。いいねは「すべて」にだけ出ます。300 行ずつ表示 |
| 詳細の下 | その配信を CSV / JSON で書き出し、または削除(受信中の配信は消せません) |

- 設定 →「アーカイブ」で保存の ON/OFF と **残す配信の数**(既定 30)。それより古い配信は自動で消えます
- デモ再生は残しません
- 保存はこの iPhone のブラウザ(IndexedDB)だけ。Safari のサイトデータを消すと失われるので、バックアップの「アーカイブも含める」でときどき書き出してください

## バックアップと書き出し(設定画面)

| 機能 | 内容 |
|---|---|
| バックアップを書き出す | 来店履歴・リスナーメモ・ギフト画像キャッシュ・設定を 1 つの JSON に。iPhone では共有シートから「ファイルに保存」や AirDrop。API キーは「含める」を ON にしたときだけ入る。「アーカイブも含める」を ON にすると過去の配信の全行も入る(ファイルは大きくなる) |
| バックアップを読み込む | JSON を選んで取り込み。**統合**(回数の多い方を残す・名前とメモは新しい方)か **置き換え**(今の履歴とメモを捨てる)を選べる。設定も入っていれば反映。アーカイブが入っていれば配信ごとに取り込む(統合なら既存に追加、置き換えなら入れ替え。統合でいいねの同じ行があれば数の多い方を残す) |
| 配信ログの書き出し | いま画面にある行(コメント・入室・フォロー・ギフト)を CSV(Excel/Numbers 用・BOM 付き)または JSON に。配信の全行はアーカイブの詳細から書き出せる |

機種変更のときは「書き出す」→ 新しい iPhone で「読み込む(置き換え)」。

## 既知の制約

- **バックグラウンドでは受信が止まります**(iOS が WebSocket を切るため)。前面に戻すと自動でつなぎ直します。「画面を暗くしない」を ON にしておくとスリープしません(iOS 16.4 以降)
- Euler の WebSocket は 8 時間で切れます → 自動で再接続します
- 無料枠は 1 日 2,500 リクエスト・Cloud WebSocket 25 本。接続 1 回 = 1 リクエストなので、配信待ちの 60 秒ポーリング(1 時間 60 回)でも PC 版と併用して収まります
- API キーは iPhone のこのブラウザにだけ保存されます(サーバーには送りません。Euler への接続 URL に載るだけです)

## 開発

```bash
npm install
npm run dev          # http://localhost:5173/tiktok-live-pocket/ (同じ Wi-Fi の iPhone からは http://<PCのIP>:5173/tiktok-live-pocket/)
npm test             # 正規化・フィード・来店カウンタ・リスナーメモ・接続状態機械・ハイライトの単体テスト(IndexedDB は fake-indexeddb)
npm run build        # dist/ に PWA 一式(manifest / sw.js / icons)
```

### 通信なしで動作確認

- アプリ内: 設定 →「▶ デモ再生(通信なし)」
- モックサーバー(Euler の封筒形式で fixture を再生):

```bash
npm run mock -- --loop
```

(Claude Code のブラウザからは `.claude/launch.json` の `mock-ws` でも起動できます)

アプリの設定 →「詳細」→ 接続先 WebSocket を `ws://localhost:8787`(iPhone からは `ws://<PCのIP>:8787`)にして「接続」。配信者名に `offline` を入れると「配信待ち」(4404)の挙動を確認できます。
`ws://` は `npm run dev` の http ページからだけ使えます(GitHub Pages の https からは混在コンテンツとして遮断されます)。

### 構成

```
src/lib/
  euler-url.ts      Euler Cloud WebSocket の URL 組み立て
  euler-socket.ts   接続状態機械(切断コード → 次の行動、バックオフ、前面復帰で再接続)
  normalize.ts      受信メッセージ → 正規化イベント(Euler v2 と PC 版 v3 の両方の項目名を読む)
  visits.ts         来店カウンタ(初見ラッチ・roomId 単位で 1 回)
  memos.ts          リスナーメモ(メモ + 前回 + よみがな。来店履歴とは別ストア)
  feed.ts           画面の行(連打の同一行更新・msgId 重複排除・入室だけ直近 500 行・配信の区切り・復元・窓描画)
  archive.ts        アーカイブの集計・絞り込み・自動削除の判定(IndexedDB 非依存)
  likes.ts          いいね集計(人ごとのタップ数・連打・ランキング。配信ごとにリセット。この集計は保存せず、アーカイブには 1 分ごとの行で残す)
  interactions.ts   やり取り(受信中の配信の行 + アーカイブ + いいねを人ごとにまとめる。並び・絞り込み)
  highlights.ts     ハイライト(日本時間の日付・1 日分の行の重ね合わせ・人ごとの集計・いいねの 1 分行・上限つき重複表)
  gift-catalog.ts   giftId → 画像/名前/💎 のキャッシュ
  db.ts             IndexedDB(来店履歴・ギフトカタログ・アーカイブの行と配信集計・画面の履歴。v5 で日付の索引を追加)
  session.ts        上記の配線 + IndexedDB への保存
src/components/     Header / FeedList / FeedRow / MemoSheet / ViewersSheet / Settings / Archive / LikeRanking / LikeToasts / Interactions / Highlights / Avatar / Badges
scripts/
  mock-ws.mjs       モック WebSocket サーバー
  make-demo.mjs     デモ用 fixture 生成
  make-icons.mjs    アイコン PNG 生成
```

### 公開

`main` に push すると GitHub Actions(`.github/workflows/pages.yml`)がテスト → ビルド → GitHub Pages へ配置します。
リポジトリ名を変える場合は `vite.config.ts` の `base` も合わせてください。
